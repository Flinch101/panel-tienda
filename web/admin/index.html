Cómo se usa: clic para elegir una celda · doble clic o Enter para editar · flechas y Tab para moverte · Shift+flechas o arrastrar para elegir varias · Ctrl+C / Ctrl+V (podés pegar desde Google Sheets o Excel) · Ctrl+D rellena hacia abajo · Supr borra · Ctrl+Z deshace.
Talles: en las columnas S a XXL escribí el stock. Si la celda está vacía, ese talle no existe para el producto; con 0 aparece como agotado. Para editar la descripción larga y las fotos, doble clic en esas celdas.
