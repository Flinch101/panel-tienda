Cómo se usa: cada producto es una fila y, debajo, una sub-fila por cada color (con su propio stock por talle y sus propias fotos). Con el botón ＋ de la fila del producto agregás un color nuevo.
Clic para elegir una celda · doble clic o Enter para editar · flechas y Tab para moverte · Shift+flechas o arrastrar para elegir varias · Ctrl+C / Ctrl+V (podés pegar desde Google Sheets o Excel) · Ctrl+D rellena hacia abajo · Supr borra · Ctrl+Z deshace.
Talles: en las sub-filas, columnas S a XXL, escribí el stock de ese color. Celda vacía = ese color no tiene ese talle; 0 = agotado. En la fila del producto los talles muestran el total (se calcula solo). Fotos: doble clic en la celda Fotos de cada color para cargar las fotos de ese color; las de la fila del producto se muestran en todos los colores.
